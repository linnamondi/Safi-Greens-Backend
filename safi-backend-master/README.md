# Safi Greens 🌱

Safi Greens is a digital platform designed to help **Mama Mbogas (fresh-produce vendors) in urban Kenya** grow their businesses by connecting them with customers online.

The platform allows vendors to:

* List and manage products
* Receive and manage orders
* Support M-Pesa payments
* Offer delivery to customers

It also includes an **AI Advisor** that provides guidance on produce storage, shelf life, spoilage detection, and reducing food waste.

### Backend

Built with **Python, Django, Django REST Framework, and PostgreSQL**, with APIs for authentication, products, carts, orders, payments, and subscriptions.
